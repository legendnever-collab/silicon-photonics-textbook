# Optical I/O model contract · Chapter 3

All quantitative models are analytical declared approximations. No Full-wave/PDK/device-performance claims. Units are explicit and model results are shared by Notebook and Figures.

1. Gaussian overlap at a common transverse plane in a common homogeneous medium, equal impedance, scalar co-polarized profiles, planar wavefronts. ψw=√(2/π)/w exp[−(x²+y²)/w²], ∫|ψ|²dxdy=1. w is 1/e field radius = 1/e² intensity radius; MFD=2w. w, dx,dy µm; λnm/1000→µm. S=w1²+w2². ηsize=(2w1w2/S)², ηoffset=exp[−2(dx²+dy²)/S], ηtilt=exp[−q²w1²w2²/(2S)], q=(2πn/λ)sinθ. θ is small angular error represented only by a transverse phase ramp; no beam propagation, facet refraction or Fresnel factor. η=product. Independent 2D complex quadrature must recover it. Real silicon modes need vector E/H normalization and facet reflection separately.
2. Relative alignment penalty η(dx)/η(0) at fixed radii and tilt. 1 dB offset d1=√(S ln10/20). Not a measured assembly tolerance/yield. Bigger modes improve lateral tolerance but increase angular phase-gradient sensitivity; these are separately visible factors.
3. Grating: e^(iβz−iωt), positive outgoing in-plane kparallel=k0nclad sinθ; θ from surface normal. Δβ=βg−kparallel−2π/Λ. First order Λ=λ/(ngrat−nclad sinθ); ngrat is a given phase/Bloch effective-index approximation, not group index or automatic Ch1 result. Positive λ/period/indices and |sinθ|≤1 checked; no radiating solution explicitly reported if violated.
4. Normalized uniform array factor F=|Σj=0..N−1 exp(i j ΔβΛ)/N|². Use stable finite complex sum (N integer 2–80). F=1 at matching, F is relative coherent phase factor only, never absolute coupling efficiency. A wavelength sweep freezes ngrat and nclad and ignores scattering strength, directionality, BOX, apodization, reflection, polarization and dispersion. No fabricated grating efficiency/bandwidth; optional relative phase-factor width is not a real device specification.
5. Edge taper/overlay figures: Conceptual. Width→mode radius is not calculated. Profiles in Gaussian experiment are independently specified hypothetical modal envelopes. No taper loss or adiabatic length predictor.
6. Jones vector j=[cosψ,exp(iχ)sinψ], unit norm. Analyzer u=[cosα,sinα] (linear); ηpol=|u†j|². ψ,χ,α degrees in UI; complex inner product in model. Complementary analyzer powers sum to1. For chi=0 deg the linear projection is cos²(psi-alpha); for chi=+/-180 deg it is cos²(psi+alpha), under the same Jones parameterization. Roundoff-only projection powers below 1e-30 are snapped to zero so exact orthogonal UI states display zero rather than spurious extreme dB; this is not a device extinction floor. e^(−iωt) is declared; circular j=(1,±i)/√2. Without a phase-sensitive analyzer, orthogonal-channel power alone cannot distinguish relative phase. Jones assumes fully polarized coherent state, not unpolarized mixtures.
7. PDL example: two orthogonal power transmissions Tx,Ty (0–1); Pout/Pin=Tx cos²ψ+Ty sin²ψ for a diagonal channel. PDL=10log10(max/min); infinite only if one channel zero. Diversity is conceptual separation of both orthogonal states, not proof of zero real loss.
8. Engineering ledger: Input mW × scalar overlap × Jones projection × independent interface survival × waveguide survival × output survival. ηinterface=10^(−ILinterface/10), waveguide survival=10^(−αdBcm Lmm/100), ηout=10^(−ILout/10). The interface residual loss explicitly excludes the already applied spatial/polarization factors to avoid double count. Each loss channel ledger is sequential, sum Pout+lost_j=Pin. No reflection allocation/return loss from the scalar deficit. No default GC/Edge platform ranking. P[dBm]=10log10(P/1mW), inverse P[mW]=10^(P[dBm]/10). Pout[dBm]=Pin[dBm]-totalDb for nonzero input/output. Zero power is -infinity dBm; total transmission loss is undefined as an input/output ratio at zero input, although the specified factor loss remains defined. Notebook input stays fixed at 1mW; this conversion changes only the unit display.

Validation: normalization; Cauchy-Schwarz bounds; equal/unequal radii, symmetry, sign reversal, offset1dB, tilt units; independent Simpson complex integration; grating signed matching/inverse relation/evanescent exclusion, finite-sum vs sine quotient with limit, reciprocal relative envelope; Jones complex projection vs Stokes/explicit components and orthogonal sums; ledger powers vs dB, unit conversion, zero/large loss, current parameter/source parity; saved setting clamping; Ch1/2 model/content/artifact preservation and browser regression.
