# SIPT-DYNAMIC-1 — Chapter12 Model Contract

Extension Curriculum E1, Independent Teaching Supplement. Single-lane NRZ-OOK intensity/direct detection, independent P0/P1 fixture, no Chapter11 state import. Not measured hardware/standards/low-BER validation.

## Planes and units
Settings: P0/P1 in mW, loss dB, rate Gb/s, Tx/Rx 3-dB bandwidth GHz, wavelength nm, eta fraction, dark nA, one-sided thermal density pA/√Hz, phase UI, threshold µA, uint seed. Internals: seconds/W/A/Hz. P1≥P0≥0; invalid UI edits are rejected; state import clamps then enforces P1≥P0. W→µW for DetectorPhysics.current. Tx intensity→single power loss→photocurrent→Rx current pole→dark DC (once). Shot formula receives only plateau photocurrent and separate dark current. Electrical noisy samples can be negative; optical intensity cannot.

## Time and filters
T=1/(rate·1e9), dt=T/samplesPerUI (default64; refinement32/64/128/256). At time n·dt, hold bit b[floor(n/S)]. Store left-boundary y[n]; then apply y[n+1]=a y[n]+(1−a)x[n], a=exp(−dt/tau). Rx update uses left-boundary Tx current, a declared cascade approximation. Individual poles use exact ZOH steps, cascade converges under dt refinement; not exact cascade at arbitrary dt. Reuse ActivePhysics.rc and DetectorPhysics.rc to obtain tau from a derived effective capacitance at R=50Ω. Ideal Tx/Rx bypass is explicit. Never reset state at bit boundaries.

Initial states are the first warm-up bit plateau; warm-up repeats the selected pattern and lasts at least max(8 bits, ceil(16·max(tauTx,tauRx)/T)), rounded up to a whole pattern length. Warm-up and measurement pattern phase align; exclude all warm-up from eye/samples/statistics. Default256 measured bits (64…4096), bounded dt for mobile. Patterns0101,0011,0000000011111111 and seeded xorshift32 bits; no PRBS claim. Seed zero maps to a documented nonzero RNG state; bit and Gaussian noise streams are separated. Seed changes do not change deterministic waveform for fixed named patterns. Seeded sequence seed intentionally changes its bits.

Eye uses measured waveform only, segments of exactly2UI starting at each measured bit boundary, all available complete segments. Labels refer to segment bit at phase∈[0.05,0.95]UI; deterministic sample interpolates two adjacent time samples without latency relabelling/CDR. Signed opening=min(bit1 samples)−max(bit0 samples), null if either class absent. Negative opening retained. Default sample phase0.7UI. Eye graphics use at most48actual complete traces, first including distinct local bit contexts then evenly distributed additional starts; do not stride-alias the alternating pattern. All measured samples contribute to opening regardless of trace display subset.

## Noise / decisions
Analog Rx first-order ENBW Bn=π f3dB/2 from integral₀∞1/(1+(f/f3dB)²)df. When Rx ideal bypass is selected, all noise is explicitly disabled/withheld because no finite measurement ENBW is declared. No infinity encoded. Plateau-conditioned Gaussian approximation: sigma_b²=[2q(Iphoto,b+Idark)·shotEnabled + i_th²·thermalEnabled]Bn. Transition/cyclostationary shot noise, continuous stochastic waveform and correlation across bit samples are not solved. One independent seeded normal variate per decision sample, no duplicate variance. Histogram/scatter use actual generated noisy decision samples, deterministic Eye remains noise-free.

Decision1 iff sample≥threshold, including exact equality. For sigma=0, conditional expected error is the deterministic error(0 or1), including equality convention. Otherwise use each sample mean/context and Gaussian tail, average over actual bit labels. Expected value is finite-pattern synthetic probability, not measured BER. Floating probabilities may underflow to0 (explicitly marked; never a verified zero-BER assertion). Gaussian erfc uses a stable continued-fraction/series incomplete gamma evaluation and is compared independently with Python math.erfc.

Q=(mu1−mu0)/(sigma1+sigma0) and equal-tail threshold=(sigma0 mu1+sigma1 mu0)/(sigma0+sigma1) are exposed only if both classes exist, opening>0, both plateau sigmas>0, and deterministic samples within each class are steady to≤1e−6·max(plateau difference,1e−15 A). Otherwise null with reason. Equal-tail is not claimed the exact minimum-BER threshold for unequal sigmas. Noise-free/allzero/reversed/ISI/missing class withhold Q. No NaN/Infinity in JSON/KPI.
