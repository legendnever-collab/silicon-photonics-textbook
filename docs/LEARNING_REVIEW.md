# Chapter 1 · 사용자 학습 검토

`dist/chapter-01.html`을 다운로드한 뒤 Chrome/Edge/Firefox/Safari 등 Browser에서 여세요. 인터넷 연결은 필요하지 않습니다. 자동 QA는 Chromium에서 수행했습니다. 다른 Browser의 실제 사용 결과는 아직 확인하지 않았습니다.

## 처음 검토할 때
30–45분을 예상하되 실제 소요 시간을 기록해 주세요. 모든 Lesson에 자유롭게 접근할 수 있고 Tutor의 정답이나 실험 완료가 진행 조건은 아닙니다. 본문을 읽으며 생각하고, 실험 전에 예상한 이유를 남기고, 결과와 비교한 뒤 자기 설명을 써 보세요. 메모는 고정형 Tutor가 자동 해석하거나 채점하지 않습니다.

Desktop에서는 왼쪽 본문과 오른쪽 Notebook을 각각 스크롤합니다. Mode의 Polarization 절을 읽으면 관련 개념도가 연결됩니다. Mobile에서는 E. Verify with Physics 안에 Notebook이 들어가며 상단 바로가기로 이동할 수 있습니다. Theme와 학습 기록은 상단에서 엽니다.

## 검토 질문
1. 설명을 읽고 Waveguide가 빛을 가두는 이유를 교재 없이 설명할 수 있었나요?
2. TIR과 Mode, Field와 Field², Material Index와 Effective Index를 구별할 수 있었나요?
3. β·Phase·Wavelength의 수식이 왜 필요한지 이해되었나요? 단위 변환이 명확했나요?
4. Tutor의 오개념 설명이 사고를 바꾸는 데 도움이 되었나요? 도움이 안 된 문장을 알려 주세요.
5. Notebook이 본문과 연결되었나요? Diagram이나 Parameter의 목적이 불명확한 곳이 있었나요?
6. Slab 계산, 실제 Strip 개념도, 합성 Bend 데이터를 구별할 수 있었나요?
7. 가장 설명이 부족하거나 지나치게 길었던 절은 어디였나요? 실제 공부한 느낌과 소요 시간도 알려 주세요.

## 자기 설명의 근거
‘이해했다’는 표시 대신 구체적인 설명을 확인합니다. 예: n_eff가 증가하면 같은 λ₀와 L에서 β와 φ는 증가하고 λg는 짧아진다. 이 사실만으로 Group Delay를 알 수는 없다. 설계 답은 선택한 R, Loss Ledger, Footprint 제약과 데이터 한계를 함께 설명한다.
