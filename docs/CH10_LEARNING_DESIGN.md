# Chapter 10 learning design

Eight A–F lessons follow original Chapter12: optical interfaces/alignment → electrical interfaces → station → registration → measurements/reference → DFT/budget → packaging review. Technical terms English, explanatory prose Korean. Gaussian alignment is deliberately introduced as an interface prerequisite before the original station operation discussion, and revisited in10.5. Other ordering and deferred topics are recorded in source mapping.

Each lesson includes independent worked calculation,3misconception choices with distinct feedback,4alternative explanations, prediction/experiment and reflection. The fixture links mechanical coordinates→optical overlap→fiber-plane signals→known-floor/reference correction→frozen acquisition→review/report. Conceptual interface/packaging diagrams are labeled separately from analytic or synthetic plots. No fake hardware data or automatically graded written reflection.

Seven selectable Notebook views and12numbered SVG figures share state. Control groups open according to view while retaining actual input nodes. Numeric Properties includes all numerical controls with validation, scrollable content, sticky Apply/Close, Escape/focus return. Figure zoom uses established horizontal scrolling. Action gates explain registration, access and reference failures; passive optical tests do not require electrical contact. Capture preserves configuration, edits and presets keep old snapshot stale, re-acquire explicit. Report and learning Backup are distinct.

Main discoveries: two interfaces multiply; one-port/pair loss differs; geometric registration does not locate optical center; reflection is not absorption; sampling minimum is not resonance fit; known reference/path lengths and detector range constrain normalization. Packaging review adds questions about actual assembly/thermal/mechanical reliability without pretending to calculate them.
