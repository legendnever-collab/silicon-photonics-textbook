# Chapter 9 learning design

Seven A–F lessons follow verified original Chapter11 contents: why → concept → units/derivation/worked example → misconception feedback → prediction/experiment → reflection. Technical terms English, explanatory prose Korean. Existing navigation, offline tutor, prediction, notes and session backup preserved.

Main causal path: nominal geometry → signed fabrication deviation → index perturbation → device-specific spectrum. Compare absolute shifts and signed pair mismatch. Each lesson has one independently calculated worked example, three tutor choices with distinct feedback, four explanatory tutor actions and a scenario/reflection task.

The same deterministic state drives numbered reading figures, the selectable notebook and report. Views: rib cross-section, contours/corner coupon, fixed corner box, normalized die field, ring spectrum, grating spectrum. Five presets act on actual state: nominal/common/local/gradient/combined. Slider inputs keep node identity and focus; prior viewport anchoring helper reused. Numeric dialog supports all controls, validation, sticky Apply/Close, native Escape and focus return. Figure zoom preserves established scrollable high-resolution SVG behavior.

No random-score quiz, fabricated empirical statistics or automatic grading of written explanations. Scenario choice is a teaching setup, not a process probability. Separate analytical covariance example is explicitly independent of sliders. Geometry-only rounding teaches why a drawn feature is not necessarily modeled optically. Ring fixed-order tracking avoids confusing FSR wraparound with shift. Grating power FWHM and product cross term distinguish efficiency and phase matching.
