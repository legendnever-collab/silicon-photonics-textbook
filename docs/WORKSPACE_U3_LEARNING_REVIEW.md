# v0.12.4 U3 Pilot · 학습 검토

대상은 **1.4 / 12.2 / 12.5**입니다. 모든79 Lesson의 U1은 유지합니다. U2·U3 전체 확대는 다음 검토 범위입니다.

1. 교재와 Guided Tutor를 읽고 원래 Prediction을 선택하거나 자유롭게 Notebook을 조작합니다.
2. 실험 화면을 확대하고, 핵심 Parameter 아래 **실험 옆에서 쓰기**를 엽니다. 교재에서 쓰던 실제 입력란이 이동합니다. 입력은 필수가 아닙니다.
3. 예측과 이유를 적고, 기준을 저장한 뒤 Parameter 하나를 바꿉니다. 위쪽 그래프·KPI와 U2 비교 결과를 관찰합니다. Frozen 저장은 명시적으로 누른 경우만 새로 취득합니다.
4. 기존 **예측과 결과를 연결해 보기**는 Lesson의 준비된 설명입니다. 실제 입력의 정답 판정이나 개인별 분석이 아닙니다. 관찰 후 설명과 Reflection은 한두 문장 또는 원하는 길이로 자유롭게 적습니다.
5. **메모를 교재로 돌려놓기**를 누르면 원래 위치로 돌아갑니다. 교재에도 회수 버튼이 있습니다. 입력 사본은 생기지 않습니다.
6. 다른 Lesson으로 갔다 돌아오거나 파일을 다시 열면 **다시 떠올리기 · 선택 사항**을 열 수 있습니다. 기존 예측 질문을 보고 먼저 생각한 뒤 메모를 엽니다. 점수나 통과 조건은 없습니다.
7. 학습 기록에서 JSON을 내보내고 가져와 Prediction·세 메모·Frozen이 보존되는지 확인합니다. 방문 여부만 별도 UI 설정이며 Backup에 포함되지 않습니다. HTML 경로/Browser가 달라지면 기록 JSON으로 옮기세요.

검토 질문: 그래프를 보며 예측·관찰·설명을 연결하기 편한가요? 자유 탐색을 방해하지 않나요? 입력의 이동/복귀가 명확한가요? 재방문 질문을 원할 때만 열 수 있나요?

자동 검증은 UI 동작과 기존 모델·기록 보존을 확인합니다. 학습 향상이나 기억 효과를 측정하지 않았습니다. Mobile은 Viewport Emulation이며 실제 Android IME·Touch·시스템 Back은 기기에서 확인해야 합니다. Source와 실행 HTML은 별도 Draft PR에서 검토하며 main에 자동 병합하지 않습니다.
