# Teaching philosophy

학습자의 사고 흐름이 제품의 중심이다. Why → Concept → Equation → Tutor → Verification → Synthesis 순서로 설명한다. 정의하기 전 새 용어를 전제하지 않으며, 충분한 문단과 Worked Example을 제공한다. 본문 스크롤은 허용하고 핵심 Notebook은 Desktop에서 독립적으로 유지한다. Mobile에서는 해당 Lesson의 실험 절 안에 같은 Notebook을 배치한다.

Offline Guided Tutor는 저자가 작성한 고정형 설명이다. 실시간 AI로 표현하지 않는다. 응답마다 개념에 대한 Feedback을 제공하고, 두 가지 이상의 오개념을 구별한다. ‘왜 그런가요 / 더 쉽게 / 수식으로’ 설명과 Notebook 관찰 안내를 제공한다. 정답률, Score, Reward, 강제 Verify Gate는 없다.

Physics Notebook에서는 Theory → Prediction → Calculation → Experiment → Explanation을 연결한다. 예측은 결과를 보기 위한 필수 관문이 아니다. 모델의 성격과 가정은 그래프 옆에 표시한다. ‘Analytical’과 ‘수치 근 찾기’, ‘검증된 실물 결과’를 혼동하지 않는다. 제시한 모델에서 옳은 계산과 실제 Silicon Strip 설계의 정확도를 구분한다.

Readable text, visible keyboard focus, 44px 이상 동작 영역, Light/Dark, Reduced Motion, 오프라인 실행, Save/Resume를 기본으로 한다. 글을 짧게 줄여 한 화면에 맞추지 않는다. 자동 테스트와 실제 사용자 학습 검증을 구분한다.
