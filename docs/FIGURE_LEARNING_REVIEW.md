# v0.1.1 · 사용자 Figure 학습 검토

`dist/chapter-01.html`을 다운로드한 뒤 Browser에서 여세요. 기존 학습 기록 JSON을 가져올 수 있고, 같은 Browser/Origin의 저장 데이터도 유지됩니다. 기술 용어는 영어, 설명은 한글입니다. 본문·Tutor 내용은 기존 Pilot과 같습니다.

1. Lesson 1.1: Core/Cladding 구조와 실제 Slab Tail을 보고, Cladding Field가 0이 아닌 이유를 설명할 수 있나요?
2. Lesson 1.2: 500nm에서 TE0/TE1을 비교하고 Signed E / Relative E²를 바꾸세요. 220nm에서 TE1이 사라지는 이유를 설명해 보세요.
3. Lesson 1.2: Numerical Scalar Map의 3개 Width와 Linear/dB를 비교하세요. Color Bar의 Quantity와 상대 정규화가 분명한가요? 모바일에서는 ‘확대’를 눌러 좌우로 볼 수 있습니다.
4. Lesson 1.3: h는 Core의 횡 방향 진동 성분, q는 Cladding 감쇠율이라는 차이가 드러나나요? Notebook의 n_eff/L을 바꾸며 Phase 수식과 Figure가 연결되는지 확인하세요.
5. Lesson 1.4: Numerical Scalar 유한 Height 결과와 y 무한 Analytical Slab의 Mode Count를 서로 구별할 수 있나요? Geometry 변화의 관찰과 모델 한계를 함께 설명해 보세요.
6. Lesson 1.5: Bend 그림이 정성적이라는 사실과 Loss 표가 합성 교육용이라는 사실이 명확한가요? R=5/10/20µm의 Loss와 Footprint를 비교한 이유를 설명하세요.

검토할 핵심은 Figure 수가 아니라 **기존 교재를 읽는 흐름을 유지하면서 개념 이해에 도움이 되는가**입니다. 특히 Figure가 너무 길거나 많아 본문을 방해한 위치, 더 필요한 설명, 실제 소요 시간을 알려 주세요. 자동 테스트는 교육 효과나 실제 Device 정확도를 검증하지 않습니다.
